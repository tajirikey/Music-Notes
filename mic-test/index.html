「マイクをはじめる」を押すと、マイクの許可を求められます。

弾いた音の順番

ここに弾いた音が順番に並びます。「ミ・ミ・ミ」のように同じ音を続けて弾いたときに、3つ並ぶかも見てください。

調整

反応しすぎるときは「反応する音量」を上げ、同じ音の連打が1つにまとまってしまうときは「打鍵の検出感度」を下げてください。


  


  

    
テストの手順

    
    
      
  1. KORG Module Pro を開き、ピアノの音色を選びます。設定でバックグラウンドで音を鳴らす機能（Background Audio など）をオンにしてください。
    2. 
      
  2. MIDI キーボードで音が鳴ることを確かめます。
    3. 
      
  3. Safari でこのページを開き、「マイクをはじめる」を押してマイクを許可します。
    4. 
      
  4. キーボードで「ド・レ・ミ・ファ・ソ」と1音ずつ弾き、正しく表示されるか見ます。
    5. 
      
  5. 「ミ・ミ・ミ」と同じ音を続けて弾き、履歴に3つ並ぶか見ます。
    6. 
      
  6. うまくいかないときは、Split View（画面分割）で2つのアプリを並べた場合も試してください。
    7. 
    

    
確かめたいこと：① KORG の音が止まらないか ② 音名が正しいか ③ 連打を数えられるか ④ 反応の速さ
